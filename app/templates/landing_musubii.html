Run it yourself

Flask, PostgreSQL with PostGIS, and GeoAlchemy2, containerised with Docker Compose. Host one institution or many from the same deployment, each with its own configuration and templates.

quickstart 
git clone github.com/TaiBIF/naturedb
cd naturedb
cp dotenv.sample .env
docker compose -f compose.yml \
  -f compose.override.yml build
docker compose -f compose.yml \
  -f compose.prod.yml up
